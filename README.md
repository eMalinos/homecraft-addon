# Homecraft – doplňky pro Home Assistant

Repozitář doplňků (add-onů) pro Home Assistant OS od [Homecraftu](https://app.homecraft.cz).

| Doplněk | Popis |
|---|---|
| [Homecraft Connector](homecraft_connector/) | Připojí Home Assistant k Homecraftu odchozím spojením: bez veřejné adresy, bez VPN. |

## Jak přidat repozitář do Home Assistantu

1. **Nastavení → Doplňky → Obchod s doplňky**.
2. Vpravo nahoře **⋮ → Repozitáře**.
3. Vlož URL `https://github.com/eMalinos/homecraft-addon` a dej **Přidat**.
4. Obchod znovu načti, doplněk **Homecraft Connector** se objeví dole v sekci *Homecraft*.
